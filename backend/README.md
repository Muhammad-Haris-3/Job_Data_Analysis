# JobMarket Backend (Flask)

Flask backend serving precomputed analytics and advanced filtered job records.

## Setup

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Generate data (recommended):

```bash
python analyze.py
```

3. Run API server:

```bash
python app.py
```

Default URL:

```text
http://127.0.0.1:5000
```

## Endpoints

- `GET /api/summary`
- `GET /api/titles`
- `GET /api/skills`
- `GET /api/trends`
- `GET /api/location`
- `GET /api/filter`
- `GET /api/all`

## Advanced Filtering Endpoint

`GET /api/filter`

Supported query params:

- `title` (string, partial match)
- `country` (string, partial match)
- `min_salary` (integer)
- `max_salary` (integer)
- `remote` (`true`/`false`)
- `limit` (integer, max 200, default 50)
- `offset` (integer, default 0)

Example:

```text
/api/filter?title=engineer&country=germany&min_salary=70000&max_salary=200000&remote=true&limit=30
```

Response shape:

```json
{
  "filters": {
    "title": "engineer",
    "country": "germany",
    "min_salary": 70000,
    "max_salary": 200000,
    "remote": true,
    "limit": 30,
    "offset": 0
  },
  "total": 123,
  "returned": 30,
  "results": [
    {
      "job_title": "Data Engineer",
      "country": "Germany",
      "location": "Berlin",
      "avg_salary": 115000,
      "remote": true,
      "job_schedule_type": "Full-time",
      "company": "Example Inc"
    }
  ]
}
```

## Data Source Behavior for `/api/filter`

- Preferred: `job_records` from `precomputed_data.json` (generated by updated `analyze.py`).
- Fallback: loads `lukebarousse/data_jobs` directly and builds filterable records at runtime.
